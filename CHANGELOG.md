## [v0.2.0] - 2026-10-05

### Highlights

- Agent/team definition registry: a persistent, queryable inventory of agents and teams discovered across registered repos, with stable identity and dangling-reference detection

### Added

- AgentDefinition and TeamDefinition ent entities, upserted from multi-agent-spec agent/team files, keyed by (repo, namespace, name) with a stable registry_xrn and source_ref ([`6eba8c4`](https://github.com/plexusone/agentplexus/commit/6eba8c4))
- GET /api/registry/agents, GET /api/registry/teams, and POST /api/registry/sync endpoints ([`6eba8c4`](https://github.com/plexusone/agentplexus/commit/6eba8c4))
- Registry sync wired into specui startup and the existing spec file watcher, coalesced through a buffered channel ([`6eba8c4`](https://github.com/plexusone/agentplexus/commit/6eba8c4))
- Team sync delegates dangling-reference detection to multi-agent-spec's Team.ValidateAgentReferences (v0.10.0), covering the roster, orchestrator, and agent-assigned workflow steps ([`6eba8c4`](https://github.com/plexusone/agentplexus/commit/6eba8c4))

### Fixed

- AgentDefinition.namespace now defaults to "" instead of being nullable, so every create path participates in the (repo_name, namespace, name) unique identity constraint ([`c6ffb46`](https://github.com/plexusone/agentplexus/commit/c6ffb46))
- Concurrent registry syncs (watcher-triggered and HTTP-triggered) no longer race on Create against the unique index; Sync is now serialized behind a mutex ([`c6ffb46`](https://github.com/plexusone/agentplexus/commit/c6ffb46))
- A team's agent membership edges now refresh on every sync instead of only when the team file's content hash changes, fixing agents that register after the team file referencing them ([`c6ffb46`](https://github.com/plexusone/agentplexus/commit/c6ffb46))
- The registry sync HTTP handler no longer echoes internal error details (filesystem paths, DB internals) to the caller ([`c6ffb46`](https://github.com/plexusone/agentplexus/commit/c6ffb46))

### Documentation

- README: document the new registry API endpoints ([`bd2609f`](https://github.com/plexusone/agentplexus/commit/bd2609f))

### Tests

- Sync test suite covering create/idempotency/content-change-detection, dangling-reference warnings, malformed-file resilience, and identity stability across file renames ([`68cd9c8`](https://github.com/plexusone/agentplexus/commit/68cd9c8))

### Internal

- Bump github.com/plexusone/multi-agent-spec dependency to v0.10.0 and update Go module dependencies ([`eefe971`](https://github.com/plexusone/agentplexus/commit/eefe971))
- Ignore local IDEATION_CHAT*.md scratch files ([`91a921a`](https://github.com/plexusone/agentplexus/commit/91a921a))

## [v0.1.0] - 2026-01-25

### Highlights

- Visual multi-agent workflow designer with React Flow canvas for exploring agent team specifications
- Gmail-style floating panels for viewing agent details with drag, resize, and minimize
- Persistent views to save and restore UI layouts using Ent ORM with SQLite/PostgreSQL

### Added

- React Flow canvas for visualizing agent workflows with custom nodes and edges ([`2987938`](https://github.com/plexusone/agentplexus/commit/2987938))
- Gmail-style floating panels for agent details with drag, resize, minimize, and close controls ([`2987938`](https://github.com/plexusone/agentplexus/commit/2987938))
- Multiple floating panels support with staggered positioning (like Gmail compose windows) ([`2987938`](https://github.com/plexusone/agentplexus/commit/2987938))
- Panel header colors match agent model type (opus=red, sonnet=blue, haiku=green) ([`2987938`](https://github.com/plexusone/agentplexus/commit/2987938))
- 2x2 grid layout for viewing up to 4 agent teams simultaneously ([`2987938`](https://github.com/plexusone/agentplexus/commit/2987938))
- Views dropdown to save, load, update, and delete UI layouts ([`2987938`](https://github.com/plexusone/agentplexus/commit/2987938))
- Markdown rendering with syntax highlighting for agent instructions ([`2987938`](https://github.com/plexusone/agentplexus/commit/2987938))
- Team selector sidebar with checkboxes for multi-team selection ([`2987938`](https://github.com/plexusone/agentplexus/commit/2987938))
- Resizable sidebar with drag handle ([`2987938`](https://github.com/plexusone/agentplexus/commit/2987938))
- Go HTTP server with agent team API endpoints ([`1ae5b0f`](https://github.com/plexusone/agentplexus/commit/1ae5b0f))
- File watcher for hot-reloading spec changes without server restart ([`1ae5b0f`](https://github.com/plexusone/agentplexus/commit/1ae5b0f))

- Environment-based database configuration (DB_DRIVER, DB_DSN) ([`1ae5b0f`](https://github.com/plexusone/agentplexus/commit/1ae5b0f))
